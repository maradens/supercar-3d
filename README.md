# Supercar 3D

An interactive 3D supercar in a single HTML file, built with [Three.js](https://threejs.org/). The body, cabin, wheels and details are all generated in code, so there are no model files or build step.

## Run it

Open `index.html` in a browser. It loads Three.js from a CDN, so you need an internet connection.

## Controls

- **Drag / scroll:** orbit and zoom the camera
- **Color swatches:** change the paint color
- **Drive:** scroll the road under the car, with a speed slider and km/h readout
- **Chase cam:** follow the car from behind
- **Headlights:** turn the headlights and beams on or off
- **Night:** switch to a night scene
- **Wheels spin / Auto-rotate:** toggle wheel spin and camera rotation
- **Photo:** save the current view as a PNG

## Features

- Smooth lofted body with wheel arches, glass cabin and paint-colored roof
- LED headlights, tail-light bar, hood vents, side intakes, diffuser, exhausts and rear wing
- Detailed wheels with rounded tires, five-spoke rims, brake discs and red calipers
- Clear-coat paint with studio reflections and soft shadows
